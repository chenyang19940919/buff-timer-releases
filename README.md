# Buff Timer

Windows 桌面計時器。時間快到時，由你自己的 Discord Bot 在語音頻道裡播報，隊友不用安裝任何東西，在語音頻道裡就聽得到。

- 多個計時器同時跑，可以設定循環
- 預告時間點可以設很多個（可以有小數，例如 2.5 秒）
- 預告時念出名稱、念你自訂的文字，或播你自己的音檔
- 最後幾秒每秒嘟一聲
- 精簡置頂模式，玩遊戲時放在角落
- 視窗縮小也會準時播報

## 1. 下載與安裝

到 [Releases](../../releases/latest) 下載最新版，兩種選一種：

| 檔案 | 說明 |
|---|---|
| `Buff.Timer_*_x64-setup.exe` | 安裝版，會建立開始選單捷徑 |
| `Buff-Timer-*-portable.exe` | 免安裝版，下載後直接執行 |

需要 Windows 10 或 11。

第一次執行如果出現藍色的「**Windows 已保護您的電腦**」，按「**其他資訊**」→「**仍要執行**」。這是因為程式沒有購買付費的程式碼簽章，不是病毒。

## 2. 建立 Discord Bot、取得 Token

每個要發起播報的人都需要**自己的 Bot**。只聽播報的隊友不用做任何事。

### 2-1 建立應用程式

1. 打開 [Discord Developer Portal](https://discord.com/developers/applications)，用你的 Discord 帳號登入。
2. 右上角按 **New Application**。
3. 輸入名稱（例如「Buff 播報員」，這會是 Bot 在 Discord 裡的名字），勾選同意條款，按 **Create**。

### 2-2 設定成私人 Bot（建議）

設成私人，別人就不能把你的 Bot 加到他們的伺服器。

1. 左邊選單點 **Installation**，把 **Install Link** 改成 **None**，按 **Save Changes**。
2. 左邊選單點 **Bot**，把 **Public Bot** 關掉，按 **Save Changes**。

> 順序很重要：一定要**先**把 Install Link 改成 None，**再**關 Public Bot。順序反過來會出現「私人應用程式不得使用預設授權連結」的錯誤，存不起來。

### 2-3 取得 Token

1. 一樣在 **Bot** 頁面，找到 **Token**，按 **Reset Token**（可能要再輸入一次 Discord 密碼或兩步驟驗證碼）。
2. 按 **Copy** 複製 Token。

> ⚠️ **Token 就等於 Bot 的密碼。** 不要貼到聊天室、不要截圖給別人。不小心外流的話，回到這裡按 Reset Token 換一組新的，舊的就會失效。

**不需要**開啟頁面下方的任何 Privileged Gateway Intents（Presence、Server Members、Message Content 都保持關閉）。

## 3. 把 Token 設定到 Buff Timer

1. 打開 Buff Timer，左邊「**Discord 語音**」區塊按「**設定 Bot Token**」（或右上角的🔑鑰匙圖示）。
2. 貼上剛剛複製的 Token，按「**儲存並連線**」。
3. 連線成功後，Discord 語音區塊會顯示 Bot 的名字。

Token 只會存在你這台電腦的 Windows 認證管理員，不會上傳到任何地方，匯出設定時也不會帶出去。

## 4. 把 Bot 加進 Discord 伺服器

你需要在那個伺服器有「**管理伺服器**」權限。沒有的話，請伺服器管理員幫你做這一步。

1. Bot 連線後，在 Discord 語音區塊按「**邀請 Bot 進伺服器**」，會打開瀏覽器。
2. 選擇要加入的伺服器，按「**繼續**」。
3. 確認權限有勾選「**檢視頻道**」、「**連線**」、「**說話**」，按「**授權**」。
4. 回到 Buff Timer，伺服器清單會自動出現。沒出現的話按「**重新整理**」。

要加進其他伺服器，按下方的「**邀請 Bot 進其他伺服器**」再做一次。

### 頻道權限

Bot 只看得到它有權限的語音頻道。如果想用的頻道沒有出現在清單裡，或旁邊顯示「（沒有連線權限）」：

1. 在 Discord 對那個語音頻道按右鍵 →「**編輯頻道**」→「**權限**」。
2. 加入你的 Bot（或 Bot 的身分組），允許「**檢視頻道**」、「**連線**」、「**說話**」。
3. 回到 Buff Timer 按「**重新整理**」。

## 5. 讓 Bot 進語音頻道

1. 在 Discord 語音區塊選「**伺服器**」和「**語音頻道**」。
2. 按「**加入語音頻道**」。Bot 會出現在那個語音頻道裡（顯示為拒聽，因為它不需要聽大家說話）。
3. 下方「**頻道裡的人**」會列出目前在頻道裡的人。

勾選「**開啟程式時自動加入上次的頻道**」，下次打開 Buff Timer 就不用再按一次。

### 播報設定

| 設定 | 說明 |
|---|---|
| 播報方式 | **語音朗讀**：念出文字；**提示音**：只嘟嘟；**兩者**：先嘟一聲再念 |
| 播報音量 | Bot 在語音頻道和你電腦上播放的音量 |
| 我的電腦也播放 | 你的電腦喇叭也會播。如果你本人也在那個語音頻道，建議**關掉**，不然會聽到兩次 |

> 另一種避免聽兩次的方法：保持「我的電腦也播放」開著，在 Discord 裡對 Bot 按右鍵 → **靜音**（只有你聽不到它，其他人照樣聽得到）。這樣你離開語音頻道時也還聽得到提示。

## 6. 建立計時器

在「**新增計時器**」填寫：

| 欄位 | 說明 |
|---|---|
| 名稱 | 播報時會念出來，例如「神聖祈禱」 |
| 分、秒 | 總時間，秒可以有小數 |
| 預告時間點 | 剩這些時間時播報，可以加很多個，例如 30 秒、10 秒 |
| 預告播報 | **念出來**：預設念「名稱 剩 ○ 秒」，也可以自己打文字，`{秒}` 會換成剩下的時間，例如「王快重生了，剩 {秒}，趕緊集合」<br>**播音檔**：改播你自己的 mp3、wav、ogg（建議 10 秒以內） |
| 最後幾秒每秒嘟一聲 | 例如 5：剩 5、4、3、2、1 秒各嘟一聲（0 = 不嘟） |
| 結束後自動重新倒數 | 循環計時，適合固定時間要補的 buff |

時間到時不會播報。

**操作方式**

- 點圓環：從頭開始
- 在圓環上按右鍵：暫停／繼續
- 齒輪：修改設定
- 計時器清單上方的「**📌 精簡置頂**」：縮成永遠在最上層的小視窗，放在遊戲旁邊

### 匯出／匯入

「資料」區塊可以把計時器和播報設定匯出成檔案，分享給隊友或換電腦時匯入。匯出檔**不含** Bot Token，也**不含**自訂音檔（換電腦後要重新選）。

## 7. 常見問題

**Q：隊友需要安裝 Buff Timer 嗎？**
不用。只有發起播報的人要執行 Buff Timer，其他人只要在同一個語音頻道就聽得到。

**Q：兩個人可以共用同一個 Bot 嗎？**
不建議。同一個 Bot 在同一個伺服器同時只能待在一個語音頻道，兩台電腦同時用同一個 Token 會互相搶。兩個人要同時播報的話，各自建立自己的 Bot。

**Q：電腦關掉或 Buff Timer 關掉會怎樣？**
Bot 會離線，播報也會停止。Bot 是跑在你的電腦上，不是雲端。

**Q：頻道清單裡找不到某個語音頻道？**
Bot 沒有那個頻道的「檢視頻道」權限。照 [頻道權限](#頻道權限) 開放後按「重新整理」。

**Q：Bot 在頻道裡但大家聽不到？**
- 確認 Bot 在那個頻道有「**說話**」權限。
- 確認大家沒有在 Discord 裡把 Bot 靜音，或把 Bot 的使用者音量調到 0。
- 確認 Buff Timer 的「播報音量」不是 0%。

**Q：改了 Bot 名字，Buff Timer 沒更新？**
按 Discord 語音區塊的「**重新整理**」。

**Q：顯示「Token 無效」？**
Token 可能被重設過。回到 Developer Portal 的 Bot 頁面按 Reset Token，複製新的貼到 Buff Timer。

**Q：設定存在哪裡？**
`%APPDATA%\com.bufftimer.app\`。計時器設定在 `settings.json`，自訂音檔在 `sounds` 資料夾。
